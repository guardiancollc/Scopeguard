# Mobile release verification checklist

- [x] Apple Developer membership active (confirmed by owner, October 28, 2026)
- [ ] App Store Connect access and app record verified
- [ ] Google Play Console account created and verified
- [ ] Native app project with bundle ID and package name
- [ ] Local native asset loading, secure session persistence, deep links
- [ ] API and Supabase auth flows tested on iOS and Android
- [ ] Photo camera/library upload and PDF export/share tested
- [ ] Account deletion in app, backend deletion flow, and public deletion instructions
- [ ] Privacy policy, terms, support contact and data safety disclosures
- [ ] Apple and Google subscription purchase compliance implemented/tested
- [ ] Store icon, screenshots, age rating and listing
- [ ] Signing, TestFlight and Play testing, crash verification
- [ ] Owner explicitly approves Production changes and store submission
